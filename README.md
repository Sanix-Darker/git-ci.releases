# GCI releases

Public release artifacts for GCI, the private CI/CD control plane for projects on your VPS.

This repository contains:

- compiled GCI binaries
- SHA-256 checksum manifests
- release signatures
- release notes

It does not contain the product source code.

Download artifacts from the [latest release](https://github.com/Sanix-Darker/git-ci.releases/releases/latest) and verify the published checksum before installation.
